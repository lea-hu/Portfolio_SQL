## Note-taking for learning GitHub

Repository vs. branch
- repository: project folder
- branch: separate working version of that project
https://medium.com/%40aneme1/git-and-github-a-beginner-friendly-guide-to-version-control-and-collaboration-7b7ac501f313

commit, push, vs, pull

Initialize this repository with a README file
- make this project immediately ready to use and clone instead of creating an empty folder
- check the box: start a new project
- leave it unchecked: if you already have an existing project folder on your computer that you want to upload to GitHub, an existing README.md online can cause merge conflicts during the first upload.
